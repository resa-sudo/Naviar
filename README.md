# NAVIAR Student

Личный учебный проект: локальный прототип веб-приложения для иностранных студентов. Помогает собрать демонстрационные документы, подтвердить распознанные данные и увидеть следующие действия и сроки.

Автор: **Маныев Ресулбег** · [resa-sudo](https://github.com/resa-sudo). Проект разрабатывается с использованием ИИ-инструментов.

> Это демонстрационный MVP для одного пользователя. Авторизации и разграничения доступа нет. Используйте только синтетические данные и тестовые документы, запускайте на `127.0.0.1`. Публичный репозиторий содержит исходники, а не работающий сервис для обработки реальных документов.

## Возможности

- Профиль студента и переключение языка основных экранов (русский/английский; часть новых экранов пока только на русском).
- Загрузка, просмотр и удаление JPG, PNG и PDF до 10 МБ.
- Паспорт, виза, миграционная карта, регистрация и три отдельных медицинских слота.
- Локальное OCR паспортов и виз через PaddleOCR; ручное подтверждение данных обязательно.
- Расчёт сроков по версионируемым правилам и календарю, список приоритетных действий.
- Локальное файловое хранилище с JSON-метаданными и автоматические тесты.

AI-помощник в интерфейсе пока является заглушкой. Облачные AI API, база PostgreSQL, аккаунты и панель сотрудников не подключены. OCR не проверяет подлинность документов. Правила и календарь требуют обновления; расчёты прототипа не заменяют проверку актуальных требований университета.

## Технологии

Python 3.12+, FastAPI, Pydantic, Uvicorn; HTML, CSS, JavaScript; опционально PaddleOCR/PaddlePaddle.

## Быстрый запуск (Windows PowerShell)

```powershell
git clone https://github.com/resa-sudo/Naviar.git
cd Naviar
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Откройте http://127.0.0.1:8000. Запускайте один процесс сервера без `--workers`. Для остановки нажмите Ctrl+C. В Linux/macOS используйте `python3` и `.venv/bin/python` вместо Windows-путей.

Основные функции и ручной ввод работают без OCR. Для распознавания дополнительно установите зависимости и загрузите модели:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-ocr.txt
.\.venv\Scripts\python.exe scripts/download_ocr_models.py
```

Загрузка весов требует интернета; обработка изображений выполняется локально. Веса, кэш и результаты экспериментов не входят в репозиторий. Для PDF доступен ручной ввод; OCR поддерживает JPG/PNG.

## Проверка

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Проверка публикационной копии 15 октября 2026: **167 тестов, OK, 1 пропущен**. Пропущенный тест требует локального образца, намеренно отсутствующего в публичном репозитории. Тесты используют временное хранилище; настоящие документы не нужны. Результат не является оценкой точности реального OCR.

Дополнительный браузерный сценарий для Windows с Chrome и Node.js:

```powershell
.\.venv\Scripts\python.exe tests/run_browser_tests.py
```

## Структура

| Папка | Назначение |

| `app/static/` | Интерфейс и стили |

| `docs/` | Архитектура и история разработки |

## Данные и ограничения

`data/` создаётся при работе и полностью исключена из Git. Также исключены `.env`, виртуальное окружение, логи, браузерные артефакты и `.document-lab/`. Публикация создана из отдельной копии без локальных пользовательских данных и прежней Git-истории.

Проверка файлов ограничена размером, MIME-типом и базовыми сигнатурами. Нет антивируса, шифрования, резервного копирования, много-пользовательской изоляции и полноценной транзакционной базы данных. Не открывайте этот сервер в интернет.

Календарь включён для 2026 года; отсутствующие годы и неподтверждённые сценарии возвращают необходимость уточнения. Имя в приветствии пока демонстрационное и не является учётной записью.
